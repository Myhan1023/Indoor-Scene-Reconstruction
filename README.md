# Indoor-Scene-Reconstruction

**轻量级 C++/OpenGL 室内场景几何重建与物理渲染引擎**

本项目主要探索从二维户型图到三维室内场景的自动化生成流程，实现了图像结构提取、二维坐标解析、三维 Mesh 构建、OpenGL 实时渲染以及基础光照与纹理映射。

## 项目流程

### 1. 图像预处理
使用 OpenCV 对户型图进行灰度化、边缘检测与霍夫线变换，提取房间结构线段。

### 2. 几何结构解析
根据线段信息计算墙体厚度与顶点坐标，并生成二维拓扑结构。

### 3. 三维场景生成
将二维坐标映射到三维空间，构建墙体 Mesh 数据并生成室内场景。

### 4. OpenGL 渲染
使用 OpenGL 完成场景绘制，并实现：
* VAO/VBO/EBO 缓冲管理
* Shader 渲染流程
* Phong 光照模型
* 纹理映射

### 5. Shader 优化
在大面积平面高光渲染过程中，尝试使用 dFdx/dFdy 对片元法线进行重建，以减少部分插值带来的光照畸变问题。

## version_2 从“几何测绘”到“语义理解”

在 3D 重建中，单纯的边缘和线段提取容易因噪声产生歧义。本项目在 **Phase 2** 中引入了**结构语义与拓扑分析**：

### 语义分割、实例分割、语义理解等视觉任务在室内场景重建中具有重要作用。通过对户型图进行语义分析，可以更准确地识别不同房间类型、家具位置等信息，从而生成更符合实际的三维场景

### 1. 门窗语义识别与空间伴生打假 (Topology-Based Door/Window Detection)
不依赖重型深度学习模型，纯靠底层几何拓扑关系，在 C++ 层面手写判定逻辑，实现 2D 户型图的精确解析：
**窗户特征识别**：基于双线平行、长度容差及中点重叠度测算，精准过滤假窗，输出结构化的 `house.json`。
**门框拓扑与伴生弧打假**：利用 `p1_connected != p2_connected` 判定一端悬空的门框基准；并首创**“回马一枪”门弧碎线搜寻雷达**，在悬空端方圆 $30\text{px}$ 内抓取开门轨迹圆弧的物理证据，完美击杀“127像素断头墙”等假门刺客。
**时序重构与解耦**：重构算法生命周期，将主墙体扫描与门弧二级遍历进行时序分离。控制台全局无垃圾日志刷屏，执行效率与代码可读性大幅提升。

### 2. 未来演进：实例分割与智能家具装配 (Future: Instance Segmentation & Parsing)
传统的像素处理有其物理极限，未来项目计划引入轻量级视觉任务（如语义分割/实例分割），进一步深化室内场景的智能理解：
**房间区域分割**：识别并闭合承重墙边界，通过连通域分析自动划分客厅、卧室、厨房等空间语义标签。
**家具实例识别**：通过模板匹配或轻量级端到端网络，识别图纸上的马桶、床、沙发等符号，提取其 2D 中心点坐标与旋转角。
**3D 资产自动对齐**：当下游 OpenGL 管线拿到语义 JSON 后，不仅能渲染墙体，还能根据标签自动在 3D 空间中实例化对应的家具 Mesh 资产。
